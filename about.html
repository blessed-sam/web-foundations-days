About QuickNotes

QuickNotes is a simple web application that allows you to quickly write down your ideas and track them. It was built as part of the Web Foundations course to help learners practice HTML, CSS, and JavaScript.

How to Use QuickNotes

  1. Add new notes
  2. View your existing notes
  3. Keep your ideas organized

Features

  • Simple and intuitive interface
  • Responsive design
  • Local storage for note persistence
Keyboard Shortcuts Action
Ctrl + Enter Add a new note
Ctrl + Delete Delete the current note
